# Cris & Paulo – Bilhar

Distribuição de instaladores Windows e Android. Este repositório não contém código privado, banco de dados ou credenciais.

Os arquivos oficiais ficam em Releases. No Windows, execute o instalador sobre a versão anterior. No Android, autorize a atualização do APK quando solicitado. Mantenha o aplicativo original para preservar a identidade de instalação.

Os dados de uso são armazenados no Supabase e exigem a conta do proprietário. Não publique backups neste repositório.
